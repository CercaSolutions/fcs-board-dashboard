# FCS Board Dashboard (prototype)

A working prototype of a board dashboard for Focused Community Strategies, built by Cerca Solutions.

- `index.html` is the whole page. It has no build step and no outside dependencies.
- All dollar figures and percentages are sample numbers. Counts marked * come from a board slide and are not confirmed.
- The "Edit the numbers" tab stands in for a spreadsheet. In the finished version the page will read a Google Sheet, and that tab will be removed.

To publish: Settings > Pages > Deploy from a branch > `main` and `/ (root)`.
