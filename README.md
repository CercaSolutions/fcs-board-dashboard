# FCS Board Dashboard (prototype)

A working prototype of a board dashboard for Focused Community Strategies, built by Cerca Solutions.

- `index.html` is the whole page. It has no build step and loads nothing from outside the repository.
- `assets/brand/` holds the FCS brand kit: the logos, the color and type tokens in `fcs-brand.css`, and the web fonts (Josefin Sans, Nunito Sans, Lora, under the SIL Open Font License). Everything follows the FCS Brand Identity Guidelines, 2022 guide updated October 2025.
- Print this page prints the tab on screen. Print all pages prints Overview, Money, Neighborhoods, and Priorities and governance, one per page, letter landscape.
- All dollar figures and percentages are sample numbers. Counts marked * come from a board slide and are not confirmed.
- The "Edit the numbers" tab stands in for a spreadsheet. In the finished version the page will read a Google Sheet, and that tab will be removed.

To publish: Settings > Pages > Deploy from a branch > `main` and `/ (root)`.
